## Overall verdict

**Minor fixes — ship-blocking is the diacritic issue in B1.** The pedagogical design is excellent across all three levels: A1 hits the right A1 grammar (to-be, articles, basic verbs, 3rd-person -s, at/in/on, basic questions); A2 expands cleanly into past simple, present continuous, comparatives, time prepositions, and `going to`/`will`; B1 systematically targets the structures that have no clean Spanish equivalent (present perfect, modals, conditionals, passive, phrasal verbs, false friends). Dialogues are conversational and have plausible distractors. The weakest file is **b1.json** because almost every Spanish string is missing its diacritics — this is a hard-to-overstate quality problem for native Spanish speakers reading 671 exercises.

## a1.json

### Critical fixes (must do)
None. A1 is clean.

### Quality concerns
- Across the file the use of `'` for both outer quote markers and inner contractions/quoted-words (e.g. `'Tengo hambre' = '___ am hungry.'`) is consistent but visually noisy. If the rendering engine treats `'` as a closing quote anywhere, prompts like `'You don't have to come.'` will look broken. Recommend confirming the renderer handles this before more content is added (it's a corpus-wide convention).
- Minor: `art2-2` prompt "En inglés 'el', 'la', 'los', 'las' todos son" — "todos" is masc-pl; "todos" agrees here because it modifies an implicit "artículos" but reads slightly off when the listed items are mixed gender. Optional polish.

### Notes on Spanish-learner targeting
Strong. Explicitly hit:
- 3rd-person -s at `en-es-everyday-verbs` lesson 2 (vrb2-1..5 + drills).
- `a/an/the` vs `el/la/los/las` collapse at `en-es-articles-basics` (art2-2 explicitly teaches "the = one article for all genders/numbers").
- "to be" mapping for hungry/thirsty/age at `en-es-tobe` lesson 4 with an explicit error-correction call-out ("ERROR MUY COMÚN: traducir literal 'I have hunger'").
- `at home / at school / at work` (no `the`) at `en-es-places-2`, with explanation.
- `to be` questions with inversion at `en-es-questions-2`.

## b1.json

### Critical fixes (must do)
- **b1.json (file-wide): systematic missing Spanish diacritics.** 179 unambiguous occurrences across 36 word forms in `prompt`/`explanation`/`description`/`title`/`text`/`intro` fields. Of zero Spanish-ish strings sampled, zero contained any of `áéíóúñ¿¡` — compared with a1 (190 strings with diacritics) and a2 (163). Top offenders: `ingles` (42), `oracion` (24), `espanol` (19), `mas` (18), `correccion` (10), `tipico` (9), `despues` (7), `tipicos` (5), `pelicula` (5), `rapido` (4), `aqui` (3), plus `traduccion`, `comparacion`, `tambien`, `avion`, `simpatico`, `quizas`, `cafe`, `gustaria`, `podria`, `dificil`, `manana`, `facil`, `util`, `numero`, `medico`, `pequena`, `comunicacion`, `asi`, `alli`, `anos`, `formacion`, `aun no`, `haria`, etc. This must be fixed before shipping to Spanish speakers — it reads as low-quality machine output. Run a deterministic find-and-replace pass keyed on word boundaries.
- **b1.json:pp2-7 / pp3-5 / ph5-6 / st1-10**: `match_pairs` exercises with duplicate right-side labels (`past simple`/`present perfect`, `for`/`since`, `S`/`I`, `past continuous`/`past simple`). Fails the unique-rights invariant. Convert each pair-row to a standalone `multiple_choice` ("Classify: 'yesterday' → past simple / present perfect / both"), or change right-side labels to be unique per row.

### Quality concerns
- **b1.json:ph1-6** (`'Can you ___ me ___ at 8?'`) options use `Ø` and a slash-pair encoding (`'pick / up'`, `'pick up / Ø'`, etc.). The intent (teach separability of pronoun objects) is correct but the option strings are confusing: a learner has to decode the typographic convention before answering. Recommend rewriting as: option strings showing the full sentence — e.g. `"Can you pick me up at 8?"` (correct) vs `"Can you pick up me at 8?"` (wrong). Same payoff, no convention to decode.
- **b1.json:ph1-7** bank includes `"ups"` as a distractor token. Fine, but the `was` distractor is irrelevant to the sentence ("She gave up") — a more useful distractor would be a real conjugation error (e.g. `gives`).
- **b1.json:c1-5** (zero conditional tap-words) `answer: "If you heat ice it melts"` — drops the comma after the if-clause that the lessons elsewhere teach. Either insert a `,` token in the bank and answer (`"If you heat ice , it melts"`) or accept the answer without comma but be consistent across the topic.
- Optional polish on `ph1-1` explanation: it concedes "mirar arriba literal usa 'look up' tambien" — true but creates ambiguity in an A1/A2 mindset; the explanation could be tightened.
- **b1.json:pp1-5** match: `drink → drunk` is the participle, but `drunk` as a standalone word reads as the adjective for "intoxicated" to an intermediate learner. Worth a small note in the explanation that it's the V3 here, not the adjective. Optional.

### Notes on Spanish-learner targeting
B1 design is the strongest in this batch:
- Present perfect: dedicated topic with explicit `desde hace`/`for`+present-perfect call-out (pp2-6), `yesterday` incompatibility drill (pp2-3), `since` vs `for` matching (pp3-x). Excellent.
- Modals: `must` vs `have to`, `mustn't` vs `don't have to` separation (m2-5, m2-6, m2-7) — this is exactly the trap point.
- Conditionals: explicit zero/first/second separation, "Si llueve, me quedo → If it rains, I'll stay" (c2-5) targeting the Spanish present-for-future mismatch. Excellent.
- Phrasal verbs: dedicated topic, separable vs inseparable taught explicitly (ph1-6, ph5).
- False friends: dedicated topic covering `actually`, `library`, `embarrassed` (←→ embarazada), `attend`, `assist`, `support`, `sympathetic`, plus `eventually`, `sensible`, `realize`, `exit`, `introduce`, `quit` in later lessons.

## Cross-cutting observations
- Per-file metadata (`code`, `instructionLang`, `targetLang`, `level`, `title`) is set to None in all three JSON files when read as-is by `json.load` (they aren't top-level fields in the file). If the loader expects them, verify the wrapper supplies them — otherwise these files only carry `description` and `topics`. Worth confirming the API consumes them correctly.
- The single-quote convention for quoted phrases is corpus-wide; recommend running a UI smoke-test on a few prompts containing both `'X'` outer quotes and `'X's'` inner contractions to confirm rendering.
- Dialogues are uniformly high quality: short, register-appropriate, two-three interactive turns each, plausible distractors. No issues found in sampled dialogues across A2 and B1.
- Pain-point coverage across all three levels matches the brief: 3rd-person -s (A1), articles (A1), to-be-for-states (A1), in/on/at (A2), false friends + phrasal verbs + present-perfect-vs-preterite (B1).
- B1 is the only file that needs hard fixes; A1 and A2 are ship-ready as-is.
